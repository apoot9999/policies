隐私政策

最后更新日期：2026 年 10 月 13 日

本隐私政策适用于浏览器扩展程序 “AI 智能划词与双语对照翻译”（以下简称“本扩展”）。本扩展是一款本地运行的 AI 翻译工具，用于帮助用户翻译网页中选中的文本，以及为网页段落生成中英双语对照阅读。

一、我们收集与处理的数据

本扩展仅在您主动触发翻译功能时，临时处理以下数据：

  • 网站内容（您处理的文本）：您在网页上选中的文本，以及（当您开启“双语对照”功能时）当前网页的段落文本。这些数据仅用于生成翻译结果。

本扩展不会收集、记录或上传以下任何信息：

  • 个人身份信息（姓名、电话、邮箱、身份证等）
  • 健康信息、财务与付款信息（您的 API 密钥仅保存在您本地浏览器，不会上传给开发者）
  • 身份验证信息、个人通讯内容
  • 地理位置、浏览历史（网络记录）、按键或鼠标活动等用户行为

二、数据的使用与流向

您选中的待翻译文本，会在您主动发起翻译时发送至您自行配置的第三方 AI 接口（如 Agnes、OpenAI、DeepSeek、Google Gemini 等兼容 OpenAI 格式的接口，由您在扩展设置中填写的服务商与 API 地址决定）。
  • 这些文本不经过开发者的任何服务器，开发者无法接收、查看或存储。
  • 翻译结果由您配置的 AI 服务商按其自身的隐私政策处理，请您同时查阅所选用服务商的隐私政策。

三、本地存储

本扩展使用浏览器本地存储（chrome.storage）仅保存以下内容，且仅存在于您自己的设备上：

  • 您的偏好设置（目标语言、界面样式、触发方式、悬浮按钮开关等）
  • 您配置的 API 服务商与 API 密钥（用于免重复输入，明文仅存于本地，不会上传）
  • 少量近期译文的本地缓存（用于相同文本免重复请求，加快响应）

以上数据均不会上传至开发者或任何第三方。

四、我们不会做的事

  • 不出售、出租或以其他方式共享用户数据；
  • 不将用户数据传输或用于扩展单一用途（翻译）之外的任何目的；
  • 不将用户数据用于广告、营销或用户画像；
  • 不将用户数据用于信用评估或放贷相关用途；
  • 不在后台静默访问网页内容，所有处理均由用户主动触发。

五、权限说明

  • storage：用于在本机保存上述配置与缓存。
  • contextMenus：用于提供“划词翻译”“一键双语对照”等右键菜单入口。
  • activeTab：在您主动点击扩展图标或使用快捷键时，临时访问当前标签页以读取选中文本或执行翻译。
  • 主机权限（*://*/*）：用于在任意网页注入内容脚本以显示翻译卡片，以及从后台向您配置的 AI 接口发起翻译请求（避免各网站 CSP 限制）。所有访问均由用户主动触发。
